# Diseño del Backoffice

Se reutilizan los patrones `workspace-*` de la aplicación clínica: barra superior, navegación lateral, cabeceras, tablas y paginación. La navegación móvil usa el mismo drawer. Pacientes y citas emplean filtros y paginación en servidor, y las secciones clínicas indican que son de solo lectura. Los estados de carga, vacío y error son explícitos. Falta validación con usuarios, lector de pantalla y contraste para evaluar WCAG; no se afirma conformidad.
