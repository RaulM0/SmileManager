# Invitaciones de clínica

El administrador de una clínica activa puede emitir una invitación por correo y rol mediante `POST /api/v1/clinics/invitations/`, con `X-Clinic-ID`. El correo se normaliza, el token se genera con aleatoriedad criptográfica, solo se guarda su hash y expira a los siete días. La emisión y el envío SMTP se realizan dentro de una transacción: un error de envío revierte la invitación; si el envío funciona pero el commit falla, el enlace recibido no funcionará. Este diseño mantiene abierto el bloqueo de clínica durante SMTP y debe evaluarse para volumen, entrega fiable y migración a un outbox antes de producción.

Configurar `TENANT_INVITATION_URL` como URL HTTPS de confianza hacia `/app/invitations/accept`, sin query ni fragmento, y configurar el correo remitente y SMTP. El servidor añade el token como fragmento, que no se envía en solicitudes HTTP de navegación. Un destinatario con cuenta debe iniciar sesión con una cuenta activa cuyo correo coincida; la pantalla presenta clínica y rol y requiere aceptación o rechazo explícito. Una persona sin cuenta puede crearla desde el acceso por invitación: el correo se obtiene de la invitación, la contraseña pasa por los validadores de Django y la creación y aceptación ocurren en una sola transacción. El flujo todavía requiere validación E2E completa antes de producción.

No se otorga membresía antes de aceptar. La aceptación y el rechazo invalidan el token y se auditan; el administrador puede revocarlo. Una invitación no modifica una membresía activa o suspendida existente. El registro impide crear otra cuenta para un correo existente y serializa los registros simultáneos que usan este flujo; otros mecanismos de creación o cambio de correo no participan en ese bloqueo y deben revisarse antes de depender de una garantía global de identidad. Los cambios simultáneos de invitación y membresía que usan estos servicios se serializan por clínica. Esto no constituye aislamiento clínico: no activar uso multiclínica hasta cerrar las vías documentadas en multitenancy-readiness.
